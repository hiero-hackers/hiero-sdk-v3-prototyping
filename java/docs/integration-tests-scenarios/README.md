# Integration test scenarios

The Java SDK integration-test suite is implemented under
`sdk/src/testIntegration/java/com/hedera/hashgraph/sdk/test/integration`.
This catalog assigns a stable, namespace-prefixed ID and a Given/When/Then
description to every declared JUnit integration test.
The implementation metadata preserves traceability to the V2 Java suite, while
the scenario prose remains programming-language agnostic and assumes Solo.

## Discovery notes

This catalog was generated by statically inspecting JUnit test declarations,
their method bodies, assertions, expected statuses, and `@Disabled`
annotations. Runnable means the test is not annotated as disabled; it does not
claim that the test passed against a live network during catalog generation.
