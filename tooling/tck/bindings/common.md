# Common transaction parameters

Every transaction method of the TCK accepts the JSON object `commonTransactionParams`
([CommonTransactionParameters.md](https://github.com/hiero-ledger/hiero-sdk-tck/blob/main/docs/test-specifications/common/CommonTransactionParameters.md)).
Its parameters are set on the transaction after it has been created, before it is signed and sent; they bind to
the mutable attributes of `Transaction`. The additional `signers` (DER-encoded private keys) are handled by the
runtime of every language: it signs the packed transaction with each key after the operator
(`PackedTransaction.sign(TransactionSigner)`), so they need no binding.

```bindings
requires {Transaction} from consensusnode.transactions

// The parameters of `commonTransactionParams`, applied to every transaction.
common commonTransactionParams -> Transaction {
    maxTransactionFee = maxTransactionFee : tinybar
    validDuration     = validTransactionDuration : seconds
    memo              = memo : string
    unsupported transactionId "by design: the transaction ID is generated by pack and cannot be set (transactions.md)"
    unsupported regenerateTransactionId "by design: regenerating the ID would invalidate collected signatures (transactions.md)"
}
```
